# نظام بنك صفوة - السيرفر الخلفي

## المتطلبات
- Node.js (أي إصدار حديث) — لا يوجد أي مكتبات خارجية مطلوبة (`npm install` مش لازم).

## طريقة التشغيل
1. حط الملفات دول كلها في نفس الفولدر:
   - `server.js`
   - `index.html`
   - `index-en.html`
   - `otp.html`
   - `otp-en.html`
   - `admin.html`
2. افتح الترمينال في نفس الفولدر واكتب:
   ```
   node server.js
   ```
3. هيظهرلك:
   ```
   ✔ الخادم شغال على http://localhost:3000
     - صفحة العميل: http://localhost:3000/index.html
     - English version: http://localhost:3000/index-en.html
     - لوحة الإدارة: http://localhost:3000/admin.html
   ```
4. افتح الرابطين دول في المتصفح (متصفحين مختلفين أو تابين مختلفين لو عايز تجرب الاتنين مع بعض).

## إزاي بيشتغل
- `index.html` لما حد يدخل اسم مستخدم وكلمة مرور ويدوس "تسجيل الدخول"، البيانات بتتبعت فعليًا لـ `server.js` عن طريق `POST /api/login`.
- `server.js` بيخزن كل الطلبات **في الذاكرة (RAM)** بس — مفيش قاعدة بيانات، ومفيش ملفات بتتكتب على القرص. لو عملت إعادة تشغيل للسيرفر، البيانات بتتصفر.
- `admin.html` بعد ما تدخل بكلمة المرور (`admin123`)، بيعمل استعلام (`fetch`) كل 3 ثوانٍ لجلب:
  - قائمة الطلبات الحقيقية (`/api/requests`)
  - عدد الزوار المتصلين فعليًا الآن (`/api/live-count`) — محسوب من "نبضات" حقيقية بترسلها كل صفحة `index.html` مفتوحة.
  - إحصائيات زيارات اليوم/الإجمالي (`/api/stats`).
- زرار "قبول"/"رفض" جوه نافذة التفاصيل بيبعت تحديث فعلي للسيرفر (`POST /api/requests/:id/status`).

## ملاحظات مهمة
- كلمة مرور لوحة الإدارة (`admin123`) متكتوبة داخل كود `admin.html` نفسه (بحث عن `ADMIN_PASSWORD`) — ده لسه حل عرض/تجريبي وليس آمنًا لبيئة إنتاج حقيقية، لأن أي حد يقدر يشوف الكود المصدري للصفحة ويلاقيها.
- البيانات (اسم المستخدم/كلمة المرور) بتتخزن وتتعرض **كنص صريح (plain text)** في لوحة الإدارة — ده مقصود لغرض العرض فقط. في نظام حقيقي، كلمة المرور لازم متتخزنش نص صريح خالص (لازم تتشفر/تتعمل لها hash).
- حقول الاسم/رقم الجوال/العنوان بتظهر "-" لأن فورم الدخول الحالي في `index.html` بياخد بس اسم المستخدم وكلمة المرور. لو عايز تجمع بيانات زيادة (رقم جوال، اسم، إلخ)، محتاج تضيف حقول لفورم تاني (زي صفحة تسجيل حساب جديد) وتوصلها بنفس السيرفر.
