# Safwa order demo

واجهة تجريبية لطلب ساعة، مبنية بملفات HTML ثابتة وسيرفر Node.js بسيط. لا توجد قاعدة بيانات أو مكتبات خارجية مطلوبة.

## التشغيل المحلي

تحتاج إلى Node.js 18 أو إصدار أحدث.

```bash
npm start
```

بعد تشغيل السيرفر افتح:

- العربية: http://localhost:3000/index.html
- English: http://localhost:3000/index.en.html
- لوحة الإدارة: http://localhost:3000/admin.html

يمكن أيضًا فتح صفحات الطلب مباشرة:

- `order-form.html`
- `order-form.en.html`

## تدفق الطلب

1. يختار العميل الساعة ويفتح نموذج الطلب.
2. يرسل النموذج بيانات التوصيل إلى `POST /api/order`.
3. تظهر صفحة تأكيد الطلب العربية أو الإنجليزية.
4. تظهر الطلبات في لوحة الإدارة أثناء تشغيل السيرفر.

صفحات التأكيد:


صفحات الخدمة:

- `track-order.html` و`track-order.en.html` لتتبع حالة الطلب.
- `privacy.html` و`privacy.en.html` لسياسة الخصوصية.
- `terms.html` و`terms.en.html` للشروط والأحكام.
- `contact.html` و`contact.en.html` للتواصل.

هذا المشروع لا يجمع أرقام البطاقات أو رموز CVV أو رموز OTP، ولا يخزن بيانات مالية حساسة.

## لوحة الإدارة

تستخدم لوحة الإدارة جلسة مؤقتة وتقرأ الطلبات من الذاكرة. كلمة مرور الإدارة تُمرر للسيرفر عبر المتغير `ADMIN_PASSWORD_HASH`، ولا ينبغي وضعها داخل ملفات الواجهة.

```bash
ADMIN_PASSWORD_HASH="salt:hash" npm start
```

البيانات مؤقتة في الذاكرة وتُحذف عند إعادة تشغيل السيرفر. هذا المشروع مناسب للتجربة المحلية فقط، وليس نظامًا مصرفيًا أو نظام دفع حقيقيًا.

## GitHub Pages

وجود ملفات HTML في مستودع GitHub لا يعني أن الموقع منشور تلقائيًا. كما أن GitHub Pages تستضيف ملفات ثابتة فقط، بينما هذا المشروع يحتاج `server.js` لتشغيل مسارات API مثل `/api/order` و`/api/requests`.

لتشغيل المشروع على الإنترنت استخدم استضافة تدعم Node.js، مثل Render أو Railway، واضبط أمر التشغيل على:

```bash
npm start
```
